Harness & Skills

数学研究のハーネスとスキル

These are public tools I use and develop for mathematical research with AI agents. They help keep research records, write and review papers, and manage LaTeX projects. The repositories are available on yoshito-ishiki-math on GitHub. To install the skills together, start with the marketplaces below.

AIエージェントと数学研究を進めるために，私が利用・開発しているツールの公開版を紹介します． 研究記録の整理，論文の執筆とレビュー，LaTeX原稿の管理を支えます． ソースはGitHubのyoshito-ishiki-mathで公開しています． スキルをまとめて導入するには，マーケットプレイスの案内をご覧ください．

How the tools fit together

三つのツールの役割

A harness gives a research project its working structure: what to read, how to record evidence, and where to resume. A skill packages instructions and supporting resources for a particular task. Kicho provides commands for the LaTeX project itself.

ハーネスは，研究プロジェクトで何を読み，どのように証拠を記録し，どこから再開するかを整理する枠組みです． スキル（skill）は，特定の作業の手順と参考資料をまとめたものです． Kichoは，LaTeX原稿の作成・ビルド・保存などを行うコマンドを提供します．

Install skills from a marketplace

マーケットプレイスからスキルを導入する

These GitHub-backed Codex marketplaces package related skills as plugins, preserving their shared references. With a Codex CLI that supports codex plugin, run the commands for the package you need.

関連するスキルを，相互参照を保ったプラグインとしてまとめて導入するための， GitHub上のCodexマーケットプレイスです．codex pluginに対応するCodex CLIで， 必要なパッケージの導入コマンドを実行します．

Math Skills Marketplace

The marketplace appears as Yoshito Ishiki Math. Its Math Paper Skills plugin installs write-research-paper, read-research-paper, and latex-paragraph-ids together. Paragraph-ID operations use Kicho's paraids command.

一覧の表示名はYoshito Ishiki Mathです． Math Paper Skillsプラグインで，write-research-paper， read-research-paper，latex-paragraph-idsをまとめて導入します． 段落IDの操作にはKichoのparaidsコマンドを使います． 

codex plugin marketplace add yoshito-ishiki-math/math-skills-marketplace
codex plugin add math-paper-skills@yoshito-ishiki-math

math-research-harness-public

A template for research directed by the mathematician working with an AI agent. It connects conversations to durable notes, claims, literature, computations, and Git checkpoints, so the next session can start from the recorded state of the project.

数学者の指示に沿ってAIエージェントと研究を進めるためのテンプレートです． 会話で得た内容を，研究メモ，主張，文献，計算，Gitのチェックポイントに結び付け， 次のセッションで記録された研究状態から再開できるようにします．

  • AGENTS.md defines the working contract; STEERING.md records current directions.
  • Each research thread keeps its claims and ledger, with evidence and unresolved questions recorded separately.
  • Workflows cover literature provenance, reproducible computation, Lean formalization, and review records tied to a specific manuscript version.
  • Numbered paperN/ directories hold independent Kicho manuscript projects. The included research example is fictional.
  • AGENTS.mdに作業規約を，STEERING.mdに現在の方針を記録します．
  • 研究テーマごとに主張と台帳を持ち，証拠と未解決の問いを区別して残します．
  • 出典を残す文献調査，再現可能な計算，Leanによる形式化，原稿の版に対応した確認記録を扱います．
  • paperN/に独立したKicho原稿を配置します．収録された研究例は，使い方を示す架空のサンプルです．

math-paper-skills

Reusable skills for mathematical manuscripts, with instructions in SKILL.md and supporting references. You can use them in a manuscript project on its own or together with the research harness.

数学原稿のための，再利用可能なスキル集です．SKILL.mdに作業手順を記し，参考資料を添えています． 個別の原稿プロジェクトでも，研究ハーネスと組み合わせても使えます．

  • write-research-paper
    Draft and revise a paper under the author's direction, including checking and repairing its exposition. 著者の指示に沿って論文を執筆・改訂し，執筆側で説明を点検して修正します．
  • read-research-paper
    Review the exposition of a frozen manuscript as an explicitly delegated independent reader. It supports sequential reading, whole-manuscript review, and bounded review of changes. 明示的に委任された独立の読者として，固定版原稿の説明をレビューします．逐次読み，全体レビュー，指定した変更箇所のレビューに対応します．
  • latex-paragraph-ids
    Maintain stable paragraph IDs in LaTeX, so comments and editing requests can refer to the same paragraph after revisions. LaTeX原稿に固定の段落IDを付け，改訂後も同じ段落を指定してコメントや編集依頼ができるようにします．

The writing and reading skills share references; install them together and preserve the repository layout. An optional author-style example can be adapted to your own preferences.

執筆用と読者用は参考資料を共有するので，両方を導入してリポジトリ内の配置を保ちます． 著者スタイルの例は， 必要な規則を選んで自分の方針に合わせるための任意採用の見本です．

Kicho

A command-line workflow manager for LaTeX research projects. It works with standard TeX tools such as latexmk, LuaLaTeX, and Biber, and provides English and Japanese project templates.

LaTeXによる研究原稿を管理するコマンドラインツールです． latexmk，LuaLaTeX，Biberなどの通常のTeX環境と組み合わせて使い， 英語・日本語のプロジェクト用テンプレートを提供します．

  • init creates a project; doctor checks the environment; check validates project files.
  • build compiles the PDF; archive saves a source, PDF, and metadata snapshot.
  • flatten combines supported source inclusions; submit prepares a local submission package, including an arXiv option.
  • initでプロジェクトを作成し，doctorで環境を確認し，checkでファイルを検査します．
  • buildでPDFを作り，archiveでソース・PDF・メタデータのスナップショットを保存します．
  • flattenで対応するソースの読み込みをまとめ，submitで投稿用ファイルをローカルに準備します．arXiv用の出力にも対応します．

Kicho is installed separately from the harness and skills. Its submission commands create files for you to review and upload.

Kicho本体は，ハーネスやスキルとは別に導入します．投稿用コマンドで作ったファイルを確認し，自分で投稿先へアップロードします．

Getting started

使い始めるには

  1. Choose the scope. For a research project, start with the harness and its owner guide. For an existing manuscript, begin with the skills. Tell the agent which files and question to work on. 作業範囲を伝える．研究プロジェクトにはハーネスと所有者向けガイドを，既存原稿の作業にはスキルを入口にします．対象のファイルと取り組む問いをエージェントに伝えます．
  2. Follow the setup guide. For Codex skills, use the marketplace commands above. The harness uses Git and uv; the skills README also explains standalone installation for Codex and Claude Code. Add Kicho and a TeX environment for LaTeX work. 導入ガイドに従う．Codexのスキルは，上のマーケットプレイスのコマンドから導入できます．ハーネスはGitとuvを使い，スキルのREADMEにはCodex・Claude Code向けの個別導入方法もあります．LaTeX作業にはKichoとTeX環境も用意します．
  3. Make a concrete request. In Codex CLI or the IDE extension, for example: $write-research-paper “Revise Section 2, preserving the mathematical claims.” Record research progress in the harness. Request an independent reader explicitly when you need one. 具体的に依頼する．例えばCodex CLIやIDE拡張で，$write-research-paper「数学的な主張を保って第2節を改訂して」と依頼します．研究の進捗はハーネスに残し，独立の読者によるレビューが必要なときは明示的に委任します．
  4. Check each kind of evidence. Review the mathematical argument, the exposition, and the compiled PDF separately. A successful build or record check alone does not establish a theorem. 確認の種類を分ける．数学的な論証，文章の説明，ビルドしたPDFをそれぞれ確認します．ビルドや記録の検査に通ったことだけで，定理が証明されたことにはなりません．

For the current skill format and discovery rules, see the official OpenAI documentation. Consult each repository's README for its setup details.

現在のskillの形式と探索方法は，OpenAI公式ドキュメントを参照してください．各ツールの具体的な導入方法は，それぞれのREADMEにあります．

Origin and public scope

元になったプロジェクトと公開範囲

The public harness and paper skills build on Haruhisa Enomoto's math-research-harness and math-paper-skills. I have added portable workflows from my own use while retaining the original MIT license and attribution. Personal research records and manuscript corpora are outside these public distributions. The research harness, math-paper-skills, and Kicho are available under the MIT license.

公開ハーネスと論文用スキルは，榎本悠久（Haruhisa Enomoto）氏の math-research-harnessと math-paper-skillsを元にしています． 元のMITライセンスと著作権表示を保持し，私の運用から再利用可能な手順を加えました． 個人の研究記録や論文コーパスは公開版に含めていません．研究ハーネス，math-paper-skills，KichoはMITライセンスで公開しています．
